WorthWise API Performance Tester

Local, browser-only smoke & warm-performance testing for the deployed Spring Boot backend. No data leaves this page except requests to your own backend.

⚠ This tool is intended for controlled testing of my own API. Do not use high request volumes against production. Requests per endpoint: no fixed limit (you choose). Concurrency max 5. Data-creating endpoints stay capped at 10. A confirmation appears if a run exceeds 700 total requests.

Test account

The account is created automatically (register → login fallback). The JWT is kept in this browser only (localStorage), is never shown in full, and is never included in exports. Data written by the tester goes only to this dedicated test account.
